# 经验与事故（为什么有这些规则）

> 本文件只记「为什么」，不记「怎么做」。规则以 `SKILL.md` 与各真源为准。
> 用途：改规则前查上下文；正常翻译流程不读。
> 来源：2026-09 至 10 的实战、使用者指出与审计；完整原文在私有工作区。

## 1. 交互与确认

### 2026-10-07：确认门弹得比产物还早
小样章节还在后台翻译，主流程就把「小样怎么样，能开批量吗」推给使用者。他面对一个还不存在的产物，只能盲答。
→ 规则：先确认文件真的存在，再触发确认门。

### 2026-10-07：让使用者确认，却不给位置
弹窗问「小样怎么样」，但没给库内链接、没给路径、也没贴内容。使用者回头找不到小样。
→ 规则：确认门必须同时给库内链接、绝对路径、正文关键片段；图片用 `![[…]]` 渲染。

### 2026-10-07：小样写进交付目录
小样直接落 `zh/<章>.md`，等于未经确认的试译混进成品稿，回滚时要手工分辨。
→ 规则：小样进 `_过程/小样/`；确认通过后才并入 `zh/`。

### 2026-10-07：小样只抽一段
一段只有一两句，看不出语感，更看不出段落之间的衔接。
→ 规则：按「小节」抽，每处 8–12 段连续文本，3–5 处，跨章，≥3000 中文字。

### 2026-10-07：小样命名分不清
产物叫 `A_整章_05_engage.md`、批次叫 `R01_2026-10-07`，看不出第几回、反馈过没有、内容是什么场景。
→ 规则：`第N回小样_YYYY-MM-DD/` 与 `第N回反馈_YYYY-MM-DD/`，中文命名，每本书各自从第一回起。

### 2026-10-07：默认跑 vs 可跳过
小样被当成必跑环节，拖慢「自读档一次跑完」。
→ 规则：默认跑，可以跳；跳过要记入规格，并在交付时说明「未做小样确认」。

### 2026-10-07：问与报分离
弹窗问「要不要做成本预估」，使用者答了，却再也看不到那个预估——它被埋在后面的长汇报里，或只写进了文件。
→ 规则：零 token 的脚本信息直接跑、直接在紧接着的消息里报；凡是问了的，答案必须当场出现。

## 2. 成本

### 2026-10-07：币种与模型档位错误
凭记忆填了人民币价、还用错了模型档位，单价比实际高约 24 倍；DeepSeek 官方页是 USD 计价。
→ 规则：只报 token 三桶；金额只在用户要求时折算，并注明币种、单位、日期、优惠时段。

### 2026-10-07：预估与实际差约 40 倍
同日同一本书，预估 50.62M、实际约 1.2M。根因是调用形态模型没跟上「译者零文件阅读、禁探索、写完即止」的 P0 优化。
→ 规则：`estimate_cost.py` 的形态常数要按实测校准；旧基线只当上限。

### 2026-10-07：只报 token
计费口径因 Agent／模型／套餐而异，合并成一个金额只会误导。
→ 规则：报缓存重发、未命中输入、输出三桶；不报总价、不追问套餐。

## 3. 源文与提取

### 2026-10-05：分段只能在翻译前
译文成形后再并段，等于在成品上二次编辑；并段只改空白，字符级零改写校验照样通过，四道门禁全不报。
→ 规则：分段只在翻译前做；`check_paragraph_map.py` 兜底。

### 2026-10-06：体检不绑格式
把体检绑在「PDF」上，EPUB／DOCX／字幕就跳过；成色Ⅰ档该照抄段落边界，Ⅲ档该先重组，却走进同一条管线，整本返工。
→ 规则：任何源文都跑 2.5.1；跳过体检的唯一理由是「这一步不需要」。

### 2026-10-07：空行块已是段落，却被短行切碎
源文 143 个空行块（＝原书 143 段）被短行启发式切到 163 块，产出一堆「一句一段」。
→ 规则：先判空行块是否已等于书的段落；是则 `--no-split`，只并块内换行。

### 2026-10-07：长行 2000 字符截断
`read` 按行截断在 2000 字符，古典／学术源文常把整节挤在一行；有的子代理静默按残行翻译，丢内容且无人察觉。
→ 规则：进入 A2 前跑 `rewrap_source_lines.py`，先 dry-run。

### 2026-10-07：EPUB 82 张图全部丢失
图片可能嵌在 `<div>` 里而不在 `<p>` 里；只扫 `<p>` 内的 `img` 会整章丢图。
→ 规则：扫描全部 `img` 标签，不限父元素；引用路径必须带 `figs/` 前缀。

### 2026-09：EPUB 续页丢 5 章
一章拆成多个 spine 文档，续页没有自己的章标题；按标题切分会整段丢，成品看起来完整、有完成标记、图片数对得上。
→ 规则：`check_epub_coverage.py` 卡口；覆盖率非 0 不进翻译。

### 2026-10-07：`chapter-figs.json` 从旧译稿反推
旧稿可能就缺章（含缺图），反推会把缺口继承下来。
→ 规则：`chapter-figs.json` 必须从 EPUB 生成，不从旧稿反推。

## 4. 段落与 Obsidian 标记

### 2026-10-05：段落门禁
「一段对一段」没有门禁时，并段不违反字符级校验，`check_numbers`／`check_structure`／`qa_report` 都不看段落边界。
→ 规则：`check_paragraph_map.py` 做门禁；Ⅰ档 tolerance 0，Ⅱ/Ⅲ档用百分比并在 README 记录。

### 2026-10-07：星号
源文 `*` 兼作列表符与斜体；译文留下单个 `*`，Obsidian 会当斜体或标签。
→ 规则：译文只允许成对 `**`；行首 `* ` 转 `- `；独立成行的 `***` 转 `---`。

### 2026-10-07：井号
`Option #1` 直译成 `选项 #1：…` 后，`#1：中文` 会整条被 Obsidian 索引成标签。
→ 规则：转义成 `\#1`；`#` 后不接数字的同样转义；改完用 `obsidian eval` 复核。

## 5. 口语源

### 2026-10：口语源按书面稿处理，整本返工
讲座／访谈／播客靠口头语、问答来回、自我更正承载意思；按书籍规范并段、删填充词、书面化，会把论证台阶压平——`error_rate` 0‰、四个脚本全绿，使用者却读不懂。
→ 规则：先定文种；口语源保留问答与路标词，不把问答压平成陈述。

### 2026-10：11 块译稿 3 处指代断裂
每块 prompt 不带前情时，代词与指示词断锚。
→ 规则：口语源每块带「前一块末尾 2 段原文 + 本块代词锚点清单」。

## 6. 术语、习语、译名

### 2026-10-07：`bottom line` 无条件替换
无条件内联 `bottom line → 净利润`，译者把 6 处 `## Bottom Line:`（小标题义）全译成「净利润：」，12 段里 6 段读不通，比不内联更差。
→ 规则：习语内联必须带语境条件；`check_idiom` 只能验证「用没用规定说法」，验证不了「用得对不对」。

### 2026-10-07：译名没内联
只内联 `Offer→方案`，漏了已定人名，译者把作者名音译错。
→ 规则：术语切片必须同时带译名；作者档案里影响逐句落笔的条目（强调方式、口语程度、称谓、单位习惯）一并内联。

### 2026-10-07：规则在库里 ≠ 译者看得到
档案写着「斜体表示强调→译文用加粗」，译者照抄了 `*斜体*`，整章 219 处符号错。
→ 规则：凡影响逐句落笔的条目，必须内联进 `{STYLE_BLOCK}`；不内联＝没写。

## 7. OCR 与扫描书

### 2026-09：页眉被译成标题
扫描书每页顶部的页眉被 OCR 读成独立块，译者当成标题译出来，一章冒出 3–8 个重复标题。
→ 规则：源文侧 `clean_running_heads.py`；译者 prompt 明写「与章名重复的独立全大写短行是页眉，丢弃」。

### 2026-10-07：目录页码错位
扫描件目录里标题与页码被 OCR 拆成不同行，按相邻配对会整串错位一格。
→ 规则：按 bbox 的 y 聚行配对；重建后用「印刷页 + 偏移 = PDF 页」与实际章首页对账。

### 2026-10-07：表格被 OCR 排成一长串
整页表格被按 (y,x) 排成一行串；多数能用 `rebuild_table_from_ocr.py` 按 bbox 还原，只有横向并格才还原不了。
→ 规则：先试表格重建，再退「原页图 + 说明」。

### 2026-09：注释每页从 [1] 重开
页脚注释不是全书连续；页脚写不下的会延续到下一页，带「（接上页）」标记。
→ 规则：注释按页定位、按章内顺序重编号；找不到引用点的孤儿注释放页末并标 `[无引用点]`。

## 8. 编排与分发

### 2026-10-07：32 个 agent 的反例
早期一本书按 1 章/agent 跑了 32 个 agent，把每 agent 2–3 万 token 的固定开销重复 32 次，省错了地方。
→ 规则：按窗口目标用量（默认 50%）合章，摊薄固定开销；不要一章一个 agent。

### 2026-10-07：路径占位符未替换，整轮空跑
派某书时把源文/输出目录写成 `{BOOK_DIR}` 忘了替换，译者一个文件都没产出。
→ 规则：发 prompt 前用「`{`」搜一遍；同批多个 agent 的路径逐个核。

## 9. 改稿与闸门

### 2026-10-07：正则吃粗体
`\*([^*]+)\*` 会把已配对的 `**粗体**` 吃成 `***粗体***`，而中文行文毫无异常。
→ 规则：要改 `*`，用占位符保护已配对标记；正则先在样本上跑一遍。

### 2026-10-07：计数与落盘不是同一机制
报告 6 处、0 处生效，而 `--expect` 照样通过：计数按行、落盘对整篇文本做一次 `sub`，带 `^`/`$` 的模式只匹配首尾。
→ 规则：落盘必须逐行；计数、落盘、样本展示三者一致；闸门自带幂等自检。

### 2026-10-07：`merge-config.json` 与轮次重命名脱节
四本书的 `suffix` 还写着 `_重译版`、指向不存在的文件，合并直接报「未找到章节文件」。
→ 规则：合并前 `--dry-run`；`suffix` 与 `zh/` 实际后缀一致，`out_name` 与成品名一致。

## 10. 质检误报

- **诗行结构**（诗歌、拉丁引文逐行排列）会被报为断句候选；抽样确认后忽略，脚本不为此收窄。
- **字母＋数字的型号/编号标签**（`1A`、`FNB`、`302`）会被判成「数字夹字母」；先按标签形态剔除再判真伪。
- **舞台提示的斜体计数在英译中下天然不对称**（英文 `and` 3 字符，中文「并」1 字符）；译文侧下限已改为 1。
- **结构件缺失报警先看是不是短强调词**；门禁只报「数量不对等」，对等与否要回原文看。
- **四个质检脚本曾硬编码只认 `.txt` 源文**，对 `.md` 源文直接报「共 0 章」——门禁静默失效比误报更危险。已改为 `.txt`/`.md` 都扫。
