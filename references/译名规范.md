# 译名规范与专名处理

翻译 agent 处理人名、地名、机构名、术语时的统一依据。依据 GB/T 19682-2005 第 5.2 条与 GB/T 19363.1-2003 第 4.4.2.5 条，叠加本管线的实操约定。

## 一、处理顺序

**裁决层级**（冲突时自上而下）：

1. **书级术语表**（本书已定的译法）
2. **作者库**（`_术语体系/<作者 slug>.md`）
3. **类型库**（`_术语体系/<类型 slug>.md`）
4. **平行文本**（已有中译本的术语与句式惯例，见第四节）

**权威来源不是裁决层，是查询方法**：先按第二节查权威来源，把结果写进对应层级（书级优先）；查不到才自译 + 首现附原文。与作者库/类型库冲突时，按上面的层级裁决，并在书级术语表注明理由。

任一层级给出译名后，同书同专名只用一个译法；出现新证据时在术语表追加修正行，不删除历史行。

## 二、权威来源清单

| 专名类型 | 首选来源 | 备用来源 |
|---|---|---|
| 英文人名 | 新华社译名室《英语姓名译名手册》 | 《世界人名翻译大辞典》 |
| 其他语种人名 | 《世界人名翻译大辞典》对应语种部分 | 该国官方中文译名、驻华使馆用名 |
| 地名 | GB/T 17693 系列《外语地名汉字译写导则》（分语种，如第 1 部分英语，2008 版） | 《世界地名翻译大辞典》、民政部地名研究所 |
| 科技名词 / 学科术语 | [术语在线](https://www.termonline.cn/)（全国科学技术名词审定委员会） | 各学科名词审定委员会公布名词、行业标准 |
| 机构 / 组织名 | 该机构官方中文名称（官网、中文宣传材料） | 外交部、国务院新闻办等官方文件用名 |
| 职务 / 头衔 | 新华社《新闻报道中的外来语》类规范、官方文件 | 通行译法（CEO → 首席执行官） |
| 商标 / 产品名 | 目标语言地区的注册名称（TikTok、YouTube 保留原名） | 官方中文官网用名 |
| 法规 / 文件 / 著作名 | 官方或既定译法（全国人大、外交部、国家图书馆） | 已有中译本扉页译名 |
| 中文名译外文 | GB/T 16159《汉语拼音正词法基本规则》 | 历史沿袭译法（如 Sun Yat-sen） |

查询顺序建议：术语在线 → 国家图书馆 / 豆瓣已有中译本 → 官方机构中文站 → 学术中文文献引用 → 自译。

## 三、分类处理规则

| 类别 | 规则 | 首现附原文 |
|---|---|---|
| 人名 | 有惯用译名的用惯用译名（如 Adam Smith → 亚当·斯密）；无则按译名手册音译 | 需要 |
| 地名 | 按 GB/T 17693 译写导则；已有惯用译名优先（如 New York → 纽约） | 需要 |
| 机构名 | 官方中文名优先；无官方名则意译并保留可检索性 | 需要 |
| 商标 / 产品名 | 目标语言地区注册名称优先；已通行音译可用（如「推特」），未通行不音译 | 不附 |
| 职务 / 头衔 | 按惯用译法（CEO → 首席执行官、CFO → 首席财务官） | 首现可附 |
| 法规 / 文件 / 著作名 | 法规、文件按官方或既定译法；著作名正文保留英文原名，首现可附中文；参考文献名可不译出 | 需要 |
| 通信地址 / URL | 直接引用原文 | 不附 |
| 缩写词 | 首现全称译出 + 附原文，如 `ROI`（Return on Investment，投资回报率） | 需要 |
| 新词 / 自造词 | 保留原文或按含义造词，明确标示并在术语表登记 | 需要 |

**附注格式统一**：

- 首现附注：`中文译名（English Original）`
- 同一专名全书只附注一次（除非跨部分分册）
- 允许的替代方案：全书末尾统一附「译名对照表」——长书术语密集时优先用此方案，正文不逐条打断

## 四、平行文本（参照译法来源）

已有中译本是术语惯例与句式语感最直接的来源，优先级高于纯理论推断，低于本书术语表。

**收集时机**：加载术语体系时，与作者库 / 类型库同步查。

**查找渠道**：

1. 国家图书馆联合目录、豆瓣读书、WorldCat——按原作者或原书名查是否有中译本
2. 同作者的其他书中译本（作者用词习惯一致，价值最高）
3. 同类型书的中译本（术语惯例，价值次之）

**存放位置**：`_术语体系/平行文本/<作者或类型>/`，每本一条记录：

```markdown
## 《中文书名》（原书名）
- 译者 / 出版社 / 出版年：
- 用途：术语对照 / 句式参照 / 风格参照
- 已提取术语：（列出与本书重叠的核心词及其译法）
- 注意：（该译本的已知问题、术语与本书冲突处）
```

**使用边界**：

- 只参照术语译法与行业惯例，**不整段照抄**——照抄既是版权风险，也会与本书风格冲突
- 中译本术语与本书术语表冲突时，以本书术语表为准，并在术语表注明分歧
- 中译本本身有误时，不因「已有译法」而沿用

## 五、自检清单（交付前）

- [ ] 同一专名全书译法唯一（跑 A4 一致性扫描验证）
- [ ] 首现附原文规则已执行，或已生成统一译名对照表
- [ ] 人名、地名有权威来源可查（译名手册 / 译写导则 / 官方名）
- [ ] 机构名使用官方中文名（无官方名则意译且可反查）
- [ ] 商标名未音译
- [ ] 缩写词首现已全称译出并附原文
- [ ] 自造新词已明确标示并登记术语表
- [ ] 中译本参照处已核对，未照抄、未沿用已知错误

## 六、常见错误

- **望文生音**：按拼写硬猜读音（如把 Sean 译「西恩」，通行译法是「肖恩」）——查手册，不猜
- **一名多译**：正文音译、图表用另一译法——以术语表裁决
- **机构名意译过度**：把有官方中文名的机构自行意译，导致读者无法反查——官方名优先
- **商标音译**：把 Twitter 译「推特」可以（已通行），把 Slack 译「斯莱克」不行——查目标语言地区注册名
- **附注不一致**：有的首现附原文、有的不附——统一规则后全书执行
- **沿用中译本错误**：中译本把某术语译错，直接沿用——核对原文后再决定
