# 书籍 README 模板

> 每本书目录下建一份 `README.md`，作为该书的索引与状态板。复制本模板后填写。
> 作用：一眼看清「当前是哪一轮、历史有哪些轮、命名有哪些例外、这本书踩过什么坑」——
> 让 `<书名>/` 目录自解释，不靠记忆。

```markdown
# <中文书名>（<原书名>）

- 原作者：<Author Name>
- 源文件：`<原书文件名>`
- 类型 / 术语库：<business / psychology / …>

## 轮次

| 日期 | 轮次 | 成品位置 | 说明 |
|---|---|---|---|
| <YYYY-MM-DD> | 首译 | `<书名> 中文全译.md` | **当前**；上一轮整体在 `_归档/` |

> 当前轮的译稿在 `zh/`、规格在 `翻译任务规格.md`、质检产物在 `_过程/`。
> 开新一轮：`python <skill>/scripts/rotate_round.py --book-dir . --name <轮次名> --apply`。

## 当前状态

- 当前成品：`<书名> 中文全译.md`（原文版 / B 只转用 `<书名>_原文版.md`）
- 形态：逐行版 / 书面整理版 / 原文版；变体并存仅在明确要求时
- 质检产物：`_过程/`（`审校差错清单.json`、`problem_report.md`、`fluency_report.md`）
- 验收：`error_rate.py` 退出码 <0 / 1 / 2>；综合差错率 <值>

## 命名例外

> 唯一登记处是《翻译任务规格.md》（例外项 + 原因 + 是否待确认），本 README 不重复维护。
> 既有产物与命名规范不一致时**不改名、不静默接受**（规则见 `references/输出结构与命名.md` 的「命名例外」）。

## 本书已知坑

> 这本书特有的源文问题（提取残缺、版式怪、OCR 噪声位置），供下一轮直接避开。

- <如：源文第 3 章开头 `"G` + `row or Die"` 被拆散>
```
