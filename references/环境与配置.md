# 环境与配置

> **公共模板。** 本机个人路径写到 `references/环境与配置.local.env`（不发布，已 gitignore）；不要把个人目录、账号或密钥写进本文件。
> 本文件不是规则真源：流程规则见 `SKILL.md`，译者规则见 `executor-prompt-templates.md`。

## 一、配置项

| 配置项 | 环境变量 | 公共默认 | 缺失时 |
|---|---|---|---|
| 书籍输出根 | `MBX_BOOKS_DIR` | `./books` | 由用户给目录，不猜 |
| 术语体系 | `MBX_TERMS_DIR` | `<输出根>/_术语体系` | 按模板新建；仍无则跳过术语检查 |
| OCR 引擎 | `MBX_OCR_EXE` | 空 | 先 `where`/搜索；找不到就问用户，不假设路径 |
| OCR 引擎目录 | `MBX_OCR_ENGINE_DIR` | `MBX_OCR_EXE` 所在目录 | 同上 |
| DSH 用量账本 | `MBX_USAGE_LEDGER` | `~/.dsh/dsh-usage/usage-ledger.json` | 如实报「取不到」，不编造实际成本 |
| Obsidian 库根 | `MBX_VAULT_ROOT` | 空 | 不做 Obsidian 复核，只跑脚本 |

## 二、本机覆盖

在本文件同目录建 `环境与配置.local.env`（不发布），写入你的实际值，例如：

```text
MBX_BOOKS_DIR=<你的书籍输出根>
MBX_TERMS_DIR=<你的术语体系目录>
MBX_OCR_EXE=<PaddleOCR-json.exe>
MBX_OCR_ENGINE_DIR=<PPOCR_api.py 所在目录>
MBX_USAGE_LEDGER=<DSH 账本路径>
MBX_VAULT_ROOT=<Obsidian 库根，可选>
```

Agent 开工前**先读 local，再读本文件**；脚本通过环境变量或 `--exe/--terms-dir` 接收。

## 三、运行环境

- Windows + Git Bash；路径用 `E:/` 或 `E:\\`，不要 `/e/`。
- Python 3.10+；依赖 `pymupdf`、`jieba`；OCR 用 Umi-OCR 自带的 PaddleOCR-json（外部程序，不随仓库分发）。
- `read` 工具按行截断在 2000 字符；长行源文先跑 `rewrap_source_lines.py`。
- 上下文窗口大小因 Agent 而异；编排与合章按实际窗口重算，不假设固定 1M。
- Obsidian CLI 可用时，涉及 `#`、`*`、`[[…]]`、图片路径的改动要做 `obsidian eval` / `obsidian tags` 复核；不可用时只跑脚本并注明「未做 Obsidian 复核」。

## 四、供应商与价格

- 不预设模型、供应商或套餐；`estimate_cost.py` 只出 token 三桶。
- 用户要求折算金额时，才读 `api-pricing.json`，并注明币种、单位、抓取日期、优惠/高峰时段。
- 不在正文写死具体厂商价格、模型名或套餐；这些属于缓存数据，不属于流程。

## 五、项目命名

- 翻译成品：`<书名> 中文全译.md`。
- 原文版 / B 只转 MD：`<书名>_原文版.md`。
- 形态变体：`_书面整理版` / `_逐行版`，只在明确要求时并存。
- 旧轮次：`_归档/<YYYY-MM-DD>_<轮次名>/`。

## 六、降级

- 非 Obsidian 环境：跳过 Obsidian 复核，其余照常。
- 无 DSH 账本：成本只报预估 token，不报实际消耗。
- 无 OCR 引擎：模式 B 停，先装或换引擎；不要假设旧路径。
- 无 `jieba`：`check_word_rarity.py` 跳过，其余质检照常。
