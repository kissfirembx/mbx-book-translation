# 脚本索引（scripts/ 目录）

> 主入口只保留「什么时候跑哪个脚本」；本文件是**用途索引**——各脚本的参数以自身 `--help` / docstring 为准，此处不再枚举。
> 2026-10-07 自 `SKILL.md` 搬出并精简（删参数手册列）。

## 一、源文缺陷 → 修复脚本 对照表

> **EPUB 源的两个静默坑（2026-10-07 实测，都靠覆盖率卡口才查出来）**：
> ① **NCX 的 `navPoint` 是嵌套的**——用正则切 `<navPoint>…</navPoint>` 会停在内层的闭合标签上，
>    把每个 Section 的**首个子项**整条吞掉（实测 31 条 TOC 只剩 25 条）。**必须用 XML 解析**。
> ② **OPF 的 `id→href` 必须用 XML 解析**——正则匹配对「属性顺序不同」会**静默漏项**，
>    漏掉的 spine 文档不会报错、只是**不进 source**（实测漏 6 个文档，其中一章 1000+ 词）。
> ③ **前置页不要整块丢**：位于 TOC 第一条之前的 spine 文档常是「免责声明/指导原则/献词/目录/评价」
>    这类**真内容**，保留为 `00_front`；只把封面这类纯图片页用 `--ignore` 排除。


新书直接按表跑体检，每种缺陷都对应「确定性脚本 + 零改写校验」。

| 源文缺陷（体检怎么发现） | 确定性修复 | 零改写校验 |
|---|---|---|
| **硬折行 + 段落边界全丢**（`preflight_probe` 报 `paras` 极少、段均几十上百行） | `scripts/unwrap_paragraphs.py`（短行＝段落末；页码标记不切断段落） | 去空白后逐字符相等（脚本内置，不等即中止） |
| **硬折行，但空行块已是书的段落**（`preflight_probe` 判「段落已成形」、段均行数 ≤4） | `scripts/unwrap_paragraphs.py **--no-split**`（只并块内换行，**不按短行切段**） | 同上；落盘后**段数必须与源文空行块数相等**（用错会多切出「一句一段」） |
| **页眉升格成 `#` 标题**（Anna's Archive 的 MD 转换；全大写、与 Title Case 真标题同名或重复 ≥2 次） | **`clean_running_heads.py` → `split_md_chapters.py`（顺序不能反）**：先删页眉，再按 `#` 切章。不先清就按 `#` 切，会切出几十个假章节（《某商业书》53 个 `#` 里 36 个是页眉） | 真标题数前后一致；每章 `#` 级标题只剩 1 个 |
| **扫描件每页的页眉被 OCR 成独立块 → 译者当标题译** | `clean_running_heads.py`（整块全大写 + 同文件 ≥2 次 → 删）；**同时要在译者 prompt 里明写「与章名重复的独立全大写短行是页眉，丢弃」**——只清源文不够，OCR 形态不稳定时仍可能漏网 | 复核：每章 `#` 级标题应当只有 1 个 |
| **段落中间的空白行**（PDF 提取产物；块尾是半句） | 暂无通用脚本：这类源文的「段落数」不是可靠不变量，按 Ⅱ/Ⅲ 档用 `--tolerance` 处理并记录 | — |
| **PDF 提取见纯数字行就当页码删**（会丢表格） | `extract_pdf_text.py` 内置的位置+数值双条件判定；实测 37 个纯数字行里只有 1 个真是页码，其余 36 个是表格单元格 | 覆盖率卡口的「数字缺失核查」 |
| **整页表格在 OCR 里被排成一长串（不是丢了）** | **先试 `rebuild_table_from_ocr.py`**（按 bbox 的 x/y 聚类还原行列）——多数表格**能完整还原**，别一上来就换图片。**只有 OCR 把相邻单元格横向并成一条时才还原不了**（实测周表 `6:00 AM BEGINNING OF DAY 1-1` 一条覆盖「时间+周一」两格）→ 那种才退到「原页图 + 说明」。 |
| **插图只导出到 `figs/`、源文无引用** | `extract_pdf_text.py` 按块顺序写 `[插图 figs/…]` 标记（自成一段）；FORMAT_BLOCK 规定译者把它转成 `![](../figs/…)` | 图片引用与文件 1:1 核对 |
| **标题去重全书共享 → 目录页把章名提前登记** | 去重必须**按文件**做（`extract_pdf_text.py` 已按此实现） | 各章首行是否为该章标题 |
| **小标题标记在提取时丢失**（独立成行、无句末标点的短语） | 不修源文；在 `{FORMAT_BLOCK}` 里明说「原文是标题就还原成标题」 | 段落门禁按对称口径跑 |
| **超长行**（单行 > 2000 字符，`read` 会静默截断） | `scripts/rewrap_source_lines.py --source-dir <书>/source_en --apply` | 去空白后逐字符相等 |
| **OCR 丢空格/粘连** | `scripts/rebuild_source_from_ocr.py` | 粘连密度、空格密度前后对比 |

## 二、改门禁之前：先跑门禁的自测

> `python evals/gates/run_gate_tests.py` —— 42 条断言，覆盖 13 个用例组（以脚本输出为准），每条都是「已知好样本必过 + 已知坏样本必报」。

**纪律**：改任何门禁/闸门脚本前先跑一遍，改完再跑一遍；**加了新规则就加用例**。理由：**修一个门禁而它自己没有测试，等于把「修 bug」换成「换 bug」**——「临时拿一本真书看看报不报」不是测试，是赌。

## 四、顶层执行脚本的通用改造要点

- **顶层执行脚本改完参数再运行**——直接运行会处理硬编码的那本书，或写入错误路径
- `BASE`（书籍根目录）：默认 `$MBX_BOOKS_DIR`（未设置时 `./books`），不必改代码
- `PRINT_OFFSET`（印刷页码→PDF 页偏移）：先抽查验证（目录条目的印刷页码 + 偏移 = 该章标题页），全书可能不一致（分册时）
- 目录页范围：用「页内含 ≥5 个章节条目模式」自动检测可省去硬编码
- `FRONT` 前置部分页范围（代序/序言）：按实际结构调整
