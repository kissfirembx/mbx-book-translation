# 执行者 Prompt 模板（翻译 / 审校）

> **为什么固化**：批量翻译时每章开一个子代理，手写 prompt 每次措辞略有差异，导致缓存前缀不稳定（未命中输入按全价计）。用同一份模板、只替换路径与要求，可让各子代理共享同一缓存前缀。
> **为什么内联**：实测成本主项是「调用次数 × 每次重发的上下文长度」，不是译文长度。模板因此把「术语 + 格式 + 图锚点」直接内联进 prompt，**译者不再读任何规范文件**（详见 `成本优化.md` P0-2）。
> **用法**：复制对应模板，替换 `{}` 占位符后发给 `subagent`。
> **举例的要求**：例子**能泛化才有用**——用通用词、占位词，或换个领域也成立的例子；不要拿某本书的实际术语举例（那种例子只唤起一本书的语境，换本书、换类型就失效，反而把译者带偏）。
>
> 🔴 **别手搓切片**：`{TERMS_BLOCK}`／`{IDIOM_BLOCK}`／`{STYLE_BLOCK}` 用脚本生成——
> `python scripts/build_slice.py --chapter <书>/source_en/<本章>.txt --author <作者 slug> --type <类型 slug>`
> 它按英文词命中筛出**本章**该用的条目，并**自动带上作者档案的「强调方式/口语程度/修辞习惯」**。
> 为什么必须自动：译者只读源文、看不到术语库，**规则在库里没内联＝没写**；
> 2026-10-07 同一天栽过两次（译名没内联、强调方式没内联），根因都是「靠人记」。

## 占位符说明

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{BOOK_DIR}` | 书籍目录绝对路径 | `<书目录绝对路径>` |
| `{NN_NAME}` | 章节文件名（不含扩展名） | `07_ch3_stats` |
| `{SUFFIX}` | 输出版本后缀 | 章节层**一律留空**——旧写法 `_重译版` 已废弃，换轮次用 `rotate_round.py` 整包归档；形态后缀只加在成品层（`_书面整理版` / `_逐行版`），不进章节名 |
| `{TITLE}` | 本章章标题（纯中文，主流程给定） | `长期：培训` |
| `{TERMS_BLOCK}` | 本章术语切片（**内联**，从书级表摘取）。⚠️ **必须同时带上已定的人名／公司名／专名译名**——只切术语不切译名，译者就会自己音译。括号内是术语库备注的**语境条件**（如「社媒语境」）——语境不符按字面义译，不算术语不统一 | `Offer→方案、Lead→潜在客户；<人名>→<本书定名>（不要自行音译）` |
| `{IDIOM_BLOCK}` | **本章习语切片**（内联，从术语库「习语与句式」表摘取；**这是「预防」的关键**） | `bottom line→分语境：会计义「净利润」／小标题义「一句话总结」（不写「利润底线」）` |
| `{FORMAT_BLOCK}` | 格式清单（**内联**，书级冻结版） | 见下方默认块 |
| `{FIGS_BLOCK}` | 本章插图锚点（**内联**，无图则写「本章无插图」） | `p043_112.png：置于「杠杆一」小节标题后` |
| `{PREV_CONTEXT}` | **前一块末尾 2 段源文**（口语源必填，防指代断锚） | 上一块最后两句英文原文 |
| `{REFS_BLOCK}` | **本块代词/指示词锚点清单**（口语源必填） | `这东西→价值；这些词→圈出来的词；B→讲义里的 1B` |

## 一、翻译执行者（每批一个，可合章）

```
你是书籍翻译执行者。把下面这一章从英文译为中文。只读源文一个文件，不要读其他任何文件、不要探索源书。

【源文件】{BOOK_DIR}\source_en\{NN_NAME}.txt
【输出文件】{BOOK_DIR}\zh\{NN_NAME}{SUFFIX}.md
【章标题】{TITLE}（用 `#`，纯中文，不带英文括注）

【术语（本章切片，必须遵守）】
{TERMS_BLOCK}

【习语（本章切片，命中即用规定说法，禁止字面直译）】
{IDIOM_BLOCK}

【格式（书级冻结版，必须遵守）】
{FORMAT_BLOCK}

【插图】
{FIGS_BLOCK}

【纪律】
- 完整翻译，不跳段、不省略、不总结、不添加解释
- **约束是帮你，不是让你机械替换**：术语表与习语表的每一条都**分语境**。如果某条规定说法放进句子里读不通（例如把独立成行的小标题 `Bottom Line:` 机械译成「净利润：」），说明你用错了语境那一栏，要按语境选对的那条
- **禁止**：解包 EPUB、渲染 PDF、grep 全书、读其他章节、读旧译稿、读术语表与规范文件（本章所需信息已全部内联在上方）
- **禁止写完再通读润色**：写完即止；只做一次机械自检——数译文空行块数，必须等于源文空行块数；不等就补回或拆开，不要交。**只调空行与段界，不得为对齐段数改标点或删页码**
- 源文里的页眉/页脚重复行按格式清单丢弃；OCR 噪声按语义纠正，无法判定处写 `<!-- 未翻译：OCR 无法辨认（说明） -->`，不要猜测、不要补写
- 文末必须写 `<!-- 本章翻译完成 -->`

【输出】只写这一个输出文件，不改动其他文件。完成后**只回一行**：
路径 | 中文字符数 | 完成标记 | 异常项（无则写「无」）
```

### `{FORMAT_BLOCK}` 默认内容（书级冻结版；每本书按实际增删后原样内联）

```
- 段首不缩进（Markdown 不渲染行首空格）；段落之间用空行分隔；中文引号「」，嵌套『』；破折号「——」；中英文之间、中文与数字之间加空格
- **段落粒度＝源文空行块**：源文**一个空行块译一个段落，不并、不拆**。⚠️ **禁止**把下面这些各自拆成独立段落——那会让整本书读起来断成一片：
  · 一句话的举例（`For example, …` 与它解释的那句在源文同一块 → 译文同一段）
  · 行动步骤（`Step 1:` 与它的说明在源文同一块 → 同段；源文本来就是 `1.`/`-` 列表的才用列表）
  · 短句强调（`Simple.`／`Done.` 这类若与上句同块，就跟上句同段）
- **列表条目之间不插空行**：源文连续的 `- `／`1.` 行 → 译文连续列出，条目与条目之间**不留空行**（留了会渲染成松散列表，观感是「一条一屏」）
- 加粗标签后不留空格（`**注意：**文本`）
- 列表符号统一 `-`；有序列表保留 `1.`
- **强调与符号（Obsidian 渲染会坏的几处）**：源文的 `*斜体*` 与 `**加粗**` **在译文里一律写成 `**加粗**`**；正文**不得出现落单的 `*`**（单个 `*` 会被 Obsidian 当斜体，`*同时*` 这类句中斜体会渲染成一坨）；行首的 `* ` 一律转成 `- `；不要写 `***…***`（粗+斜）
- **井号必须转义**：源文 `Option #1`／`Play #1`／`Step #2` 里的 `#` **写成 `\#1`**（不加反斜杠会出事——`#1：中文…` 在 Obsidian 里**整句被索引成标签**，实测标签索引里就有 `#1：把每月新增客户数翻倍（也就是`）。机理：标签 = `#` 紧跟非空白字符，纯数字不算、但接了非数字就算，中文与全角标点是合法标签字符，于是一直吃到空格）。`#` 后面不接数字的（如 `#tag` 式写法）同样转义为 `\#`
- **独立成行的分隔符**：源文单独占一行的 `***`／`* * *`（作者用来分段）→ 转成 `---`（Markdown 水平线）；**不要保留成可见星号，也不要当加粗处理**
- **源文里的 HTML 表格（`<table>`/`<thead>`/`<tr>`/`<th>`/`<td>`）一律转成 Markdown 表，不得原样保留 HTML 标签**（实测：同一本书两个译者，一个转了、一个把 460 个标签原样留着——规则没写就各干各的）
- 金额/百分比/数字保留半角；折扣 `X% off` = 降价 X% = 打 (10 − X/10) 折；倍数 `Nx more` = 「是……的 N 倍」，禁止「高 N 倍」
- 不得留英文单位缩写残渣（`/wk`、`/mo`、`3.5B`）——写成中文表述（「每周 X 美元」「35 亿」）
- 现成习语优先：目标语有现成说法就用（`race to the bottom`→杀价到底、`bottom line`→**分语境**：会计义「净利润」／`## Bottom Line:` 小标题义「一句话总结」／段首引导语「归根结底：」「说白了，」——**不要一律写「净利润」，否则整段标题读不通**），禁止自造解释性译法
- **「不添加解释」只禁新增内容**：原文自带的括号注释、缩写全称、公式、单位符号一律保留，不得以「不添加解释」为由删掉（删了算漏译）
- **术语切片是「按英文词命中」筛出来的，会有假命中**：一个词是不是术语，看它在句子里的角色、不看拼写；切片里带了这条术语，不等于这句话必须套规定译法
- 标题层级：章 `#` / 节 `##` / 子节 `###`；源文独立成行的 `#1 …` → `### \#N …`；
  **源文有标题标记的，照源文的层级**；**标记在提取中丢了、但形态明显是标题的（独立成行、无句末标点、居中式短语），还原成标题**。
  **判据：原文是标题就是标题。**
- 源文 `[PDF 第 X 页]` 标记忽略，不进正文
- **源文独立成行的 `---`**：**默认是作者分段符，保留为 `---`**；只有与 `[PDF 第 X 页]`/页脚页码明确对齐、且前后句被截断时，才按分页断点删除并接回。不要仅凭「前后句像被截断」就删。判据记入《翻译任务规格.md》。
- **源文里的 `[插图 figs/pXXX_Y.ext]` 标记**（PDF 源内嵌插图，独占一行）：**换成独占一行的 `![](../figs/pXXX_Y.ext)`**——路径照标记里写的原样搬运，不要自己拼文件名（文件名由提取脚本按页生成，猜必错）。标记出现在哪一段的前面，图就放在那一段之前。
- 重复页眉/页脚丢弃（不得升格为标题；逐页版权行全书只保留一次）
```

### `{STYLE_BLOCK}` 中文表达约束（每本书默认内联）

> **目的只有一个：别让译文比原文更肿。不是「把原文改得更好」——原文怎么写，就怎么译。**
>
> ⚠️ **本书作者档案（`_术语体系/<作者 slug>.md`）里凡是「影响逐句落笔」的条目，必须一并内联进本块**——
> 至少包括：**强调方式**（全大写／斜体怎么处理）、**口语程度**、**称谓习惯**、**单位与数字习惯**。
> 只把档案写在库里、不内联，等于没写：译者只读源文，看不到档案。
> 实测教训：档案写着「斜体表示强调→译文用加粗」，译者照抄了 `*斜体*`，整章符号错。规则不内联＝没写。

**可以做（做的都是「去掉译者自己加上去的东西」）**：

- **删填充词**：译文里的「其实、事实上、某种程度上、值得注意的是」若是译者加的，删掉
- **名词化改动词**：「进行讨论 / 作出决定 / 予以处理 / 实现增长」→「讨论 / 决定 / 处理 / 增长」——**虚化动词是中文翻译腔的头号特征**
- **被动改主动**：中文能主动就主动，`X was done by Y` → 「Y 做了 X」。**原文刻意用被动的（强调受事、不知道谁做的）要保留**
- **弱动词 + 副词 → 一个强动词**：「快速地跑」→「飞奔」、「大声地说」→「喊道」
- **拆长句**：英文长句的中文语序容纳不下时可拆成 2–3 个短句。**只在读不通时拆，且不得增删语义、不得改变段落数**（`check_paragraph_map.py` 门禁）
- **英语的委婉量词不直译**：`a bit more X`／`that extra bit of X`／`a touch of X`／`a little extra Y` 不要译成「多一点 X」「一点点 Y」——中文不在抽象名词上这么叠（「多一点安心」读不通）。换成中文天然的说法（`that extra bit of peace of mind` → 「图个安心／想更保险」）

**不许做（这几条是「写作规则」，不是「翻译规则」——照搬会替作者改写）**：

- ❌ **不许为了「有力」删掉原文的限定词**：`somewhat / arguably / in some cases / tends to` 必须译出来
- ❌ **不许加强或削弱原文的语气**：原文平实就平实译，原文强调就照译
- ❌ **不许调整句长与节奏**：原文若通篇等长句，就照译——句长是**症状不是目标函数**（这一条已由文体判据实证推翻，别再照搬「越短越好」）
- ❌ **不许一律删副词**：只删**方式副词**，且是原文没有的那些；总副词率不是指标（同表第 2 条：海明威副词率 5.8%，高于平均）

> 来源：`dbs-ai-check` 的 22 条 AI 写作特征（取 #19 中文翻译腔、#14 句子节奏、#17 连接词三条）+ 海明威判据总表**可迁移**的部分。
> `dbs-ai-check` 本体是**诊断工具**（默认只识别、逐条追问），形态上不适合批量质检译稿——所以拿它的**特征清单**用，不"跑它"。

### 插图块（由主流程填 `{FIGS_BLOCK}`，不给译者自行定位的机会）

- 有图：`p043_112.png：置于「杠杆一：获得更多客户」小节标题后`（一行一图，含落点依据）
- 无图：`本章无插图，不要添加任何图片引用`

## 二、双语审校者（抽检，每本 2-4 章）

```
你是双语审校者。对照英文原文审校中文译文，找出差错。只读原文与译文两个文件。

【原文】{BOOK_DIR}\source_en\{NN_NAME}.txt
【译文】{BOOK_DIR}\zh\{NN_NAME}{SUFFIX}.md

【术语（必须遵守）】{TERMS_BLOCK}

【做法】抽 3 段（章首段、含数字/专名段、章末段；含表格或金额密集的章加抽 2-3 段）逐句对照原文。重点查：漏译、错译、数字/金额错误、术语不一致、专名错译、比较对象颠倒、否定词丢失。
折扣换算：`X% off` = 降价 X% = 打 (10 − X/10) 折，译反即 I 类。
倍数表述：`Nx more` = 是……的 N 倍（`1.33x more` = 贵 33%），译成「高 N 倍」即 I 类。
`X% more` 译「高出 X%」是正确中文，不要误报。
源文若是 OCR 重建的扫描件，OCR 噪声不算译者差错。

【差错分类（GB/T 19682-2005 附录 A.1）】
- I 类：核心语义差错，或关键字词（数字）、句段漏译/错译
- II 类：一般语义差错、非关键字词漏译、用词/语法错误、表述含混
- III 类：术语不准确/不统一/不符合惯例，或专名错译
- IV 类：计量单位/符号/缩略语未按规定译法

【输出】只输出 JSON 数组，字段：class、chapter、location、source、target、note。无差错输出 `[]`。不要修改任何文件，不要输出 JSON 以外的内容。
```

## 三、定向审校者（`check_fluency.py` 之后，只审挑出的段）

> 替代原「双语审校抽 3 段 + 单语通读 10%」两遍盲读。输入不是整章，而是 `check_fluency.py`
> 排出的 top 5% 可疑段——**脚本先定位，审校只判定**。成本约为盲读全书的 1/12。
> 盲读的做法已被废除（按比例烧 token 且无标准），因为翻译腔没有权威阈值、判定器做不出来。

```
你是定向审校者。下面是从全书筛出的若干「最像翻译腔」的段落，每段附英文原文与中文译文。
逐段判定：哪里不像地道中文、哪里有硬译腔或英文残渣，并给出改法。

【术语（必须遵守）】{TERMS_BLOCK}

【待审段落】每段格式：位置 / 英文原文 / 中文译文 / 脚本给出的偏离项
{FLUENCY_BLOCK}

【若本次附的是「生僻用词候选」清单】（来自 `check_word_rarity.py`，格式：候选词 / 出现次数 / 上下文）
逐条回答一个问题即可：**「这个词在中文里是自然说法吗？」**
- 是 → `false_positive`（含：分词伪影如「举个」「我担」、音译专名、行业术语、作者刻意造词）
- 否 → 给出更常见的同义说法（如「被摄住」→「被震住」）
- 判据是「中文读者会不会觉得别扭」，不是「词典里有没有」。不要为凑数硬改。

【做法】
- 只看提供的段落，不要通读全书、不要读其他文件。
- 对每段先判脚本报警是不是真问题：公式段、清单编号段、专名/数字密集段常是**假阳性**，
  直接标 `false_positive` 即可，不要为凑数硬改。
- 真问题给出：问题类型 + 最小修改建议（改词序/换习语/拆长句/去英文残渣），不做整段重写。

【问题类型（GB/T 19682-2005 附录 A.1）】
- 逐字硬译腔、用词或语法错误、表述含混 → II 类
- 专名/术语/单位译法不当 → III 或 IV 类
- 仅当修改触及语义（漏译、错译）才归 I/II 类

【输出】只输出 JSON 数组，字段：class、location、source、target、suggest、note。
无问题输出 `[]`。不要修改任何文件。
```

## 四、口语源（字幕 / 讲座 / 访谈 / 播客转录）专用块

> 2026-10-06 立。起因：一份**人工校验过的规整字幕**被按书籍规范处理——译文并段、删口头语、书面化改写，`error_rate` 0‰、四个脚本全绿，**用户读不懂**。语义校验全过不等于读者跟得上讲者。

先跑成色体检拿档位，再按档位选块：

### `{FORMAT_BLOCK}` 口语源版本（按成色档位取一行）

```
- **成色Ⅰ档（已人工校验）**：一段对一段——源文用空行分隔的段数，译文必须完全一致；不许合并、不许拆分、不许调序、不许删段。源文一行常是半句，中文也照样断行，段末没说完是正常的
- **成色Ⅱ档**：照译；仅在「上一行无句末标点且下一行以小写开头」处做最小合并，其余段落边界不动
- **成色Ⅲ档**：本档的段落重组已在**翻译前**由确定性脚本完成并过了两级零改写校验，译者面对的就是重组后的段落，照 Ⅰ 档执行
- 段首不加空格缩进（字幕体例）；引号「」，嵌套『』；破折号「——」；中英文与数字间加空格
- 保留讲者的口头语与路标词的中文对应（嗯／呃／对吧／你看／你知道／所以／但是／问题在这里）——**不要删、不要换成书面连接词**
- 保留问答来回与自我更正：**不得为了「通顺」把问答压平成陈述**，不提炼、不概括、不书面化
- 被讲解的英文词（`but`／`however`／`anomaly`／`flow words` 这类）保留英文原词，可紧接中文
- 术语切片按英文词命中筛，会有假命中：看句中角色，普通义按普通义译
- 源文独立成段的他人引文照译，**不加 `>` 符号**（一段对一段，加了就破坏对齐）
- 数字、页码、时间保留半角
- 无插图时不得添加任何图片引用
```

### 前情块（口语源必填，拼在术语块之前）

```
【前情（上一块末尾，仅供理解指代，不要翻译、不要写进输出）】
{PREV_CONTEXT}

【本块代词/指示词锚点】
{REFS_BLOCK}
```

理由：`P0-2 译者零文件阅读` 与 `P0-3 译者禁探索` 约束的是**译者**，所以跨块上下文必须由编排层内联下发，而不是让译者去翻全书。实测缺这一项时，指代跨块断锚是必然事件（某讲座 11 块里被抓到 3 处：「这东西」「这些词」「B」）。

### 口语源的输出契约

```
路径 | 源文段数/译文段数 | 异常项（无则写「无」）
```

**段数必须自报**——它是编排层唯一能一眼看出对齐是否被破坏的信号，也是 `check_paragraph_map.py` 的对照值。

## 五、使用建议

1. **先译 1 章做风格基准**，后续各章把那一章填进 `{STYLE_REF}`（仅主流程比对，不再让译者读它）
2. **分批 8 个/批**（并发与成本平衡点）
3. **同一本书连着跑完**，不要跨天（缓存 TTL 小时到天级，跨天前缀按未命中重算）
4. 审校 JSON 收集后**先复核再改**——实测审校者会误判（把已有的译文报成漏译、把风格建议报成差错）
5. 修正后给清单条目加 `"status":"fixed"`，`error_rate.py` 会自动跳过已修正项
