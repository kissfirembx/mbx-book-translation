## 语义不变量（本类型的意译边界）

> 用途：目标语要通顺，但下面这些维度**一个都不能丢**，每丢一条按 II 类及以上记差错。
> 与 `{STYLE_BLOCK}` 的分工：STYLE_BLOCK 管「别替作者改写」，本栏管「本类型特有的不可丢失维度」。
> 只保留本类型真正会翻坏的项，不要全抄；古典／韵文／宗教类另加「改写不得生造意象与结局」。
> 落地：规范冻结时把本栏并入书级 `{FORMAT_BLOCK}`（每章原样内联）；不并入＝没写。

- 否定与范围：`not / no / never / few / only` 的辖域不扩大、不缩小
- 情态与承诺强度：`must / should / may / tends to / arguably` 原强度译，不升级不降级
- 限定与例外：`in some cases / except / unless / up to` 必须译出
- 数量与量级：数字与量级原样，不四舍五入、不改单位制
- 时间与条件：`before / until / as soon as` 的相对关系不颠倒
- 因果与归因：谁因谁果、谁说的（转述观点 ≠ 作者认同）不混
