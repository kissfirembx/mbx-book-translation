# 输出结构与命名规范（所有模式统一）

> 主入口保留「轮次规则」这一条最要紧的硬约束与 `rotate_round.py` 命令；本文件保存完整目录树、命名规则表、命名例外与硬性规则。2026-10-07 自 `SKILL.md` 搬出（主入口减重）。

全部产物集中在开工确认的输出目录下（用户指定，或默认 `$MBX_BOOKS_DIR/<书名>/`）。

长文/连载同样用 `<标题>/`；没有书级目录时 `source_en/` 按标题或自然小节切，成品名 `<标题> 中文全译.md`，不强行造书级章节。

## 目录树

```
<书名>/
│
├── <原书>.pdf|epub       # ── 输入区（跨轮稳定，不随轮次搬动）
├── source_en/            #    源章节切分（txt，每页含 [PDF 第 X 页] 标记）
├── figs/                 #    图片
├── ocr/  ocr_md/         #    （扫描版才有）分页 OCR JSON、OCR 重排中间 MD
├── chapter-figs.json     #    （EPUB 才有）章 → 有序图片名
├── merge-config.json     #    合并配置
│
├── zh/                   # ── 本轮区（脚本的固定入口；开新一轮时整包归档）
├── 翻译任务规格.md        #    本轮规格（开工产物，固定文件名）
├── <书名> 中文全译.md     #    本轮成品（A3 产物，唯一，带目录）
├── _过程/                #    本轮的全部中间与质检产物
│   ├── 审校差错清单.json
│   ├── problem_report.md          （qa_report.py）
│   ├── fluency_report.md          （check_fluency.py）
│   └── 翻译规范与术语表.md         （A2 建表；A5 沉淀后删除）
│
└── _归档/                # ── 历史轮次，整包存放
    └── <YYYY-MM-DD>_<轮次名>/{zh/, <成品>.md, 翻译任务规格.md, _过程/}
```

**下划线开头 = 非当前产物，一眼可辨。** 质检产物（《审校差错清单》《problem_report》
《fluency_report》）一律落 `_过程/`，不再散在书根——`error_rate.py` 的 `--errors`、
`qa_report.py` 的输出路径都按此传参。

## 翻译任务规格（固定文件名）

每本书顶层一份 `翻译任务规格.md`，开工时写、收工回填。最小字段：

| 字段 | 内容 |
|---|---|
| 模式 | A / B+翻译 / B 只转 / C |
| 质量档 | 自读 / 精确 |
| 成色 | Ⅰ / Ⅱ / Ⅲ（Ⅲ 是否已在翻译前重组） |
| 文种 | 书面源 / 口语源 |
| 输出目录 | 绝对路径或库内路径 |
| 小样 | 跑 / 跳过（谁定的、日期） |
| 已知风险 | 源文缺陷、表格、注释、图片 |
| 成本 | 预估 token 三桶；实际（账本取不到就注明） |
| 验收 | I 类 / 综合差错率 / 门禁退出码 |

## 命名规则

| 对象 | 规则 | 示例 |
|------|------|------|
| 章节文件 | `NN_英文短名.txt/.md`，NN 为两位序号按书内顺序 | `07_ch3_levers.txt` |
| 图片（PDF 源） | `p<页码>_<xref>.png` | `p073_181.png` |
| 图片（EPUB 源） | 保持原文件名 | `image_rsrc2XN.jpg` |
| 当前成品 | `<书名> 中文全译.md`，顶层唯一 | `某书 中文全译.md` |
| 原文版 / B 只转 MD | `<书名>_原文版.md`，顶层唯一 | `某书_原文版.md` |
| 当前译稿 | `zh/NN_<英文短名>.md`（**不带轮次后缀**） | `zh/03_ch3_levers.md` |
| 任务规格 | 固定名 `翻译任务规格.md`（顶层，当前轮） | |
| 历史轮次 | `_归档/<YYYY-MM-DD>_<轮次名>/`，整包（`zh/`、成品、规格、`_过程/`） | `_归档/2026-09-15_二轮/` |
| 质检产物 | `_过程/` 下，文件名固定（`审校差错清单.json`、`problem_report.md`、`fluency_report.md`） | |
| 形态变体成品 | **仅在明确要求时**两版并存；默认只留当前成品；各自带形态后缀，不互相覆盖 | `<书名> 中文全译_逐行版.md`、`<书名> 中文全译_书面整理版.md` |
| 形态变体译稿 | 放独立目录（如 `zh_line/`），避免破坏 `zh/` 与 `source_en/` 的一一对应 | `zh_line/01_intro.md` |

**命名例外**：既有产物的目录名与规范不一致时（如 `zh_white/`、`en_source/`），不改名、也不静默接受——在《翻译任务规格.md》登记「例外项 + 原因 + 是否待确认」，并在交接时告知用户。新增产物一律按规范命名。

## 硬性规则

1. `zh/` 与 `source_en/` 文件一一对应（文件名相同、扩展名不同）——A4 双语审校与章节核对依赖此映射
2. 成品之外不产出其他散落 md——中间产物都在各自目录内
3. 交付时输出目录不落任何过程产物（《翻译规范与术语表.md》等 A2 产物交付前删除）；脚本临时产物放系统临时目录
4. **段落边界守恒**：成色Ⅰ档源的译文段落边界必须与源文逐段一致（`check_paragraph_map.py` 门禁，退出码 0）。**段落整理只能在翻译前做**；翻译后发现并段，回切源文边界，不靠改名放行。只有翻译前主动重组的版本，才加 `_书面整理版` 并在前言声明形态
5. **顶层唯一（轮次规则）**：顶层只留当前一份成品、一份 `zh/`、一份 `翻译任务规格.md`；明确要求的形态变体除外。开新一轮先跑 `rotate_round.py`，不并存两版。旧稿在 `_归档/` 里仍在，但**不参与任何流程**（译者禁读旧稿、不作术语依据）
