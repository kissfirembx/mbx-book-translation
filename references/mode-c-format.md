# 模式 C：文本层纯格式转 MD（不翻译）

> 从 `SKILL.md` 移出的详细步骤。**适用**：已有文字层、无需翻译（原语言即目标语言），目标只是高质量 Markdown。

**产物**（在开工确认的输出目录下）：`figs/` + `<书名>_原文版.md`。无 `source_en/`、`zh/`。B 只转 MD 用同一个产物名。

## 流程（确定性脚本为主，AI 不参与机械处理）

1. **C1 提取**：PyMuPDF span 级提取（保留每字坐标/字号/字体）；章节边界取 PDF 内置 TOC 优先。
2. **C2 版面重建**：`scripts/rebuild_layout.py`——按「上一行无句末标点则拼接」重建段落、清理纯数字页眉页脚。**骨架版**：不做缩进/行距判断、栏序修正、非数字型页眉页脚清理；需要这些能力时改用 OCR 版管线（有 box 坐标）或按书补规则。
3. **C3 图片**：先跑 `scripts/extract_figs.py --pdf <书.pdf> --book-dir <书目录> --ranges <页码范围.json>` 导出图片（命名 `p<页码>_<序号>.<ext>`），再跑 `scripts/extract_captions.py` 绑定图注（图下小字→题注紧跟图、叙述式图注保留为正文、图中文字按 bbox 剔除）。`extract_captions.py` 自身不导出图片，缺文件时写注释提示。
4. **C4 真表格**：`scripts/restore_tables.py`——描边线判定后还原为 Markdown 表。**当前只处理文字表格**；图片形式的数据图需人工保留或按图处理，脚本不自动保留整图。
5. **C5 符号规范化**：`scripts/normalize_symbols.py`——书名号/引号/破折号/全半角统一；英文对话/英文词引号白名单保留。
6. **C6 识别错误修正**：`scripts/fix_recognition.py`——混淆表+上下文规则（数字/字母、ISBN、已知乱码段整段还原）。
7. **C7 交「人在回路质检门」**：跑 `scripts/qa_report.py`，用户复核 → 反馈 → 预设修复 → 复查，清零才交付。

## 表驱动

所有可枚举错字/混淆/符号规则放 `references/data/` 配置文件（脚本默认读取），脚本内保留基线表作为回退；新增错误只加表项不改逻辑（省 token、可持续沉淀）。
