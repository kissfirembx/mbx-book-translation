# 源文体检（体检细则）

> 主入口只保留「跑体检 → 拿档位 → 定分支」这条决策链；本文件保存指标定义、门槛理由、实测参照与各分支细节。2026-10-07 自 `SKILL.md` 搬出（主入口减重）。

## 适用范围（不绑格式，2026-10-06 立）

体检对**任何源文类型**都要跑——PDF／EPUB／DOCX／txt／字幕（srt/vtt/ass）都跑「成色体检」，PDF 再附加「版面雷达」。

**跳过体检的唯一理由是「这一步不需要」，不是「格式不对口」**——跳过会让成色Ⅰ档（该照抄段落边界）和Ⅲ档（该先重组）走进同一条管线（2026-10-06 教训，代价整本返工）。

## 成色体检（任何源文，零成本，先跑）

跑 `scripts/preflight_probe.py <源文> --out <目录>`（PDF 加 `--kind pdf`，文本类默认 `--kind text`），输出 `probe.json` + `probe_report.md`。

**文本类指标与健康值**：

| 指标 | 含义 | 健康值（Ⅰ档） |
|---|---|---|
| `end_punct_rate` | 行末有句末标点的行占比 | ≥ 0.85 |
| `cross_line_rate` | 上一行无句末标点、且下一行以小写开头的行占比（一句被切成两行） | ≤ 0.10 |
| `glue_per_kchar` | 小写紧接大写的次数 / 千字符（丢空格粘连，如 `HowtoWin`） | ≤ 1.0 |
| `space_density` | 空格数 / 字符数（英文正常 ≈ 0.17） | ≥ 0.12 |
| `timecode_lines` / `speaker_lines` | 时间码行数 / 说话人标记行数 | 仅作分栏与转录来源提示 |

**档位判定（一次定死）**：

- **Ⅲ 档**（成色差）：`end_punct_rate < 0.60` **或** `cross_line_rate > 0.25` **或** `glue_per_kchar > 2.0`
- **Ⅰ 档**（成色好）：`end_punct_rate ≥ 0.85` **且** `cross_line_rate ≤ 0.10` **且** `glue_per_kchar ≤ 1.0`
- **Ⅱ 档**：其余

**实测参照**（2026-10-05 某 YouTube 讲座导出字幕，人工校验过）：`end_punct 0.972 / cross_line 0.01 / glue 0.2 / space 0.173` → **Ⅰ 档**。

`glue` 门槛定 2.0 而非 3.0：健康英文的噪声底 ≈ 0.2（来自 `YouTube`／`UChicago`／`PhD` 这类专名），2.0 相当于每 500 字符一处粘连，已足以让译者误判词边界。

**硬折行的判别（2026-10-07，真实试水暴露）**：`preflight_probe.py` 按**物理行**量行末标点率，于是「段内硬折行」（段落边界完好、只是段内换了行）与「真粘连断句」被当成同一回事、一律报 Ⅲ 档——后者该按标点重组段落，前者照抄就行，**处置完全相反**。实测一本硬折行的书：空行分段 483 个、段均 3.4 行，却被判 Ⅲ 档。

处置：脚本已加「段均行数」判别（**段数 ≥50 且段均行数 ≤4 且无时间码 → 判「硬折行，段落边界照抄」**）。

## 版面雷达（PDF 源专用；EPUB 源跳过）

跑 `scripts/preflight_probe.py <PDF> --kind pdf --out <目录>`，输出逐页字符数/图片数/描边线数/可疑字率，作为各分支执行基线与 QA 对照。

- **文字层可信度**：脚本按正则统计「可疑字率」（数字字母混淆形态的行占比）；字体 ToUnicode 逐字比对**未实现**，可疑页仍需人工抽样
- **真表格**：描边线（`get_drawings` 直线/矩形）计数 → 提示「可能图片数据图/装饰线」，区分真伪需人工看图
- **公式 / 多栏 / 两端对齐**：脚本**不检测**；由人工抽样判断断句与「假表格」风险
- **插图 / 图注**：脚本统计图片数与 bbox；题注 vs 叙述式的分类由 `extract_captions.py` 在提取阶段处理
- **跨页断句风险**：脚本**不检测**；在版面重建阶段按「前段无句末标点」规则处理

EPUB 源跳过本节，改跑 `check_epub_coverage.py`（见 `references/mode-a-text.md` 的 A1 第 9 条）。

## 提取完整性卡口（切分完成后必跑）

- **PDF 源**：`scripts/check_pdf_coverage.py --pdf <书.pdf> --source-dir <书>/source_en` 逐页核对文本是否都进了 `source_en/`，退出码非 0 就补提取再翻译。已知误报是**表格页**（PDF 按列读取，源 txt 常写成按行的 Markdown 表，顺序不同导致该页低分）——先看缺失词条再判真伪。
- **EPUB 源**：`check_epub_coverage.py`（见 A1 第 9 条）。

## 长行预折行卡口（进入 A2 之前必跑，任何书源都要过）

`read` 工具**按行截断在 2000 字符**，古典/学术类源文常把一整节挤在一个物理行里——实测有源文把整节挤在一行、单行上万字符，译者读到的就是被砍掉尾巴的残行：有的子代理自己用 pwsh 补读（多付往返），有的**静默按残行翻译**（丢内容且无人察觉）。跑：

```
python scripts/rewrap_source_lines.py --source-dir <书>/source_en            # 先看统计（dry-run）
python scripts/rewrap_source_lines.py --source-dir <书>/source_en --at-markers --sep blank --apply
```

- 脚本只增删空白与换行，落盘前自带**两级零改写校验**（字符级 + 结构级），不通过就拒绝落盘；断点优先级、`--max-len`、备份位置（`source_en_旧_长行版/`）见脚本 docstring
- ⚠️ **凡是会动换行的脚本，必须同时过 `check_paragraph_map.py`**——并段只改空白，**不违反字符级校验**，只挂字符级校验等于把「段落被合并」静默放行（2026-10-05 实测盲区）
