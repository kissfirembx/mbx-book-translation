# 模式 B：扫描 PDF OCR 转 MD

> 从 `SKILL.md` 移出的详细步骤。**适用**：无文字层（文本层判定「字符/页 < 50」）的扫描版；要翻译时叠加 A2-A5，只转 MD 时止于 B6 + 质检门。**只转 MD 的产物是 `<书名>_原文版.md`，不建 `zh/`。**

## B1. OCR 引擎（本机 PaddleOCR-json）

引擎路径：默认值见 `references/环境与配置.md`（可用 `MBX_OCR_EXE` 覆盖）；如引擎位置变更，先 `where` 或搜索确认，**不假设旧路径**。

**通用驱动**：`scripts/ocr_pdf.py`（PaddleOCR-json + PyMuPDF，按页 JSON，断点续传）。

```bash
python scripts/ocr_pdf.py --pdf <书.pdf> --out-dir <书>/ocr --dpi 150 --apply
python scripts/ocr_pdf.py --pdf <书.pdf> --out-dir <书>/ocr --pages 1-3 \
  --md-out <书>/source_en/<书>_ocr.md --apply
```

- `--md-out` 生成带 `[PDF 第 N 页]` 的合并 MD；纯扫描书走这条路，再用 `rewrap_source_lines.py` 处理长行、按标题切章（`split_md_chapters.py` 或人工）。
- `rebuild_source_from_ocr.py` 只在**已有带页码标记的 `source_en`** 时用；纯扫描、原本没有 source 的书不要硬套。
- 150dpi 快速模式：约 2-3 秒/页（1000 页约 45 分钟）；**300dpi 高精度：约 3 秒/页——引用点/脚注密集的书必须用**。
- 输出按页 JSON（含 box 坐标 + 文本），已存在的页跳过；CPU 推理为主，有 NVIDIA GPU 可换 CUDA 版引擎提速。

## B2. 章节定位（扫描版的关键难点）

- 页脚页码识别：每页最后一行纯数字 = 印刷页码；建立 PDF页↔印刷页 映射（验证偏移：抽查「目录条目的印刷页码 + 偏移 = 该章标题所在 PDF 页」）
- 目录页解析：正文印刷页码 = PDF 页 - 偏移（全书偏移一致时）
- 无页码章标题（目录中只有「第X章」独立行）：用正文页的「数字+第X章」混拼行（章首页页脚页码+章名，如「92第四章」）定位
- 篇/章层级：挂起逻辑（无页码标题挂起，遇到下一个有页码条目时注入到前 2 页）
- 章节边界最可靠信号：**正文页眉**（每页顶部重复的章名）——章号变化处 = 章节边界；页眉还能给出无副标题章的完整标题

## B3. 段落重建（排版质量核心）

OCR 行坐标（box）是关键：

- **段首缩进检测**：中文段落首行缩进 2 字符（x0 比续行右移约 45px@150dpi）——这是最可靠的段落边界信号，比行距阈值可靠
- 行距 >90px 辅助分段；段尾短行（<15 字）并入前段
- 页眉（顶部居中短行）、页脚（底部纯数字/罗马数字）、章名页眉——全部过滤
- 跨页断开：前段无句末标点（。！？」）→ 与下一正文段合并；段落在节标题处断开 → 延续段合并回前段、节标题下移到合并段后
- 索引区（词条列表）：按 OCR 原始行输出，不做段落合并

## B4. OCR 错字修复（高频表，结合语义）

**高置信混淆表**：见 `references/data/confusions.json`（进人→进入、自已→自己、垒断→垄断等）；`fix_recognition.py` 读该表，不在文档里维护第二份。**单本术语**（如「来塞斯→米塞斯」「基据」）记入该书作者库或书级术语表，不进通用表。

- 破折号「——」常被识别为「一一」「--」「一—」：按上下文恢复（「第——」「另——」「——种/个/般」等 → 单「一」；其余 → 破折号）
- 语义判断后保留的正确词：必需（必需+名词 ✓）、今人（=现代人）、不得已、设有（=假设有）、导人（=引导人）
- **单本书专属术语**（如「行动人」「基据」）记入该书作者库或书级术语表，**不进通用混淆表**

## B5. 注释处理（难点中的难点）

原书脚注规律：

- **每页从 [1] 重新编号**（不是全书连续！）
- 页脚写不下的注释**延续到下一页底部**，带「（接上页）」「（转下页）」标记
- 上标标注符号 OCR 常漏识别——用 300dpi 重跑引用点缺失的页

处理方案：

1. 注释内容用 OCR 定位到所属页（clean 8-gram 索引匹配）
2. 引用点（[n] 标志）在正文段落中：注释移到「标志所在段」后；找不到标志的 → 移到**所属页内容末尾**（该页最后正文段后，且必须是完整句结尾——不切断跨页句子）
3. 同一注释被多次引用 → 放第一次引用处
4. 正文误标为注释的（OCR 把引用点后正文当注释）→ 还原为正文段（用 OCR 位置判断：内容在正文区 y<80% 且无注释特征 → 正文）
5. 交叉核对：每页「页脚注释数 vs 正文引用数」——注释数 > 引用数 = 引用点漏识别 → 300dpi 重跑

## B6. 注释编号策略

- 原书每页 [1] 起 → MD 中按章内顺序重新编号（第 k 个注释 ↔ 第 k 个引用点）
- **找不到引用点的孤儿注释**：放所属页内容末尾，并在注释前标 `[无引用点]`；它不参与 k↔k 编号
- 编号与正文引用点一致（用户对照用）
- 双链（Obsidian 块引用 [[#^id]]）可选用——用户默认要简单数字 [n]
